# Security Policy

If you discover a security issue, do not open a public issue with exploit
details.

Preferred reporting path:

1. Open a private GitHub Security Advisory if you have access.
2. Otherwise, open a GitHub issue with a short summary and request private
   follow-up in the description.

Please include:

- package or example affected
- platform or runtime version
- reproduction steps
- whether the issue affects persisted sync data, acknowledgements, or the
  transport boundary

We will prioritize issues that could expose data, corrupt durable state, or
cause silent synchronization loss.
